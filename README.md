# 🧠 MeetingMind - AI Meeting Preparation Agent

> Hackathon theme: **AI Agents That Learn Using Hindsight**

## Problem
Before every meeting you dig through old notes, try to remember what you promised, which
follow-ups slipped, and what worried the other person.

## Solution
MeetingMind remembers every meeting with each contact in **Hindsight**, then writes a
personalised brief before the next one. After the meeting you paste notes; the agent extracts
the important facts, stores them as memories, and the next brief adapts.

## Key features
- Structured extraction of topics, decisions, commitments, concerns, action items, preferences, unresolved and *resolved* issues
- Hindsight recall before every meeting; brief shows *which memories shaped it*
- Memory / Learning view: timeline, first-vs-latest brief comparison, live recall, Hindsight reflect
- One-click Sarah Johnson demo scenario
- Friendly errors, logging, no secrets in code
